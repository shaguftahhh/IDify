# 🎓 Student ID Card Generator

### Learn Today. Lead Tomorrow.

## 📌 Introduction

The **Student ID Card Generator** is a simple and user-friendly web application that allows students to create digital identity cards by entering their personal and academic details and uploading a profile photograph.

The application instantly generates a digital student ID card that can be previewed and printed, reducing the need for manual ID card designing.

## 🎯 Objectives

- Generate digital student identity cards.
- Reduce manual ID card designing work.
- Provide a simple and user-friendly interface.
- Display student information dynamically.
- Enable easy printing of generated ID cards.

## ✨ Features

- **Student Details Form:** Enter name, student ID, course, department, academic year and blood group.
- **Photo Upload:** Upload a personal photograph.
- **Instant ID Generation:** Automatically displays entered information on the ID card.
- **Live Preview:** Preview the generated ID card.
- **Print Option:** Print the ID card or save it as PDF using the browser.
- **Responsive Design:** Simple layout for different screen sizes.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd Student-ID-Card-Generator
```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser or use the Live Server extension.

5. Enter student details and upload a photograph.

6. Click **Generate ID Card** to view your digital ID.

7. Click **Print ID Card** to print or save it as PDF.

## 💡 Methodology

1. Create an HTML form to collect student details.
2. Use CSS to design the form and ID card layout.
3. Use JavaScript to retrieve the entered information.
4. Display student details dynamically on the ID card.
5. Use FileReader to display the uploaded photograph.
6. Provide a print option for the generated ID card.
