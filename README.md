## 💡 Why IDify?

Designing student ID cards by hand is slow and repetitive. IDify removes that
work: fill in a short form, upload a photo, and get a clean digital ID card
instantly, right in your browser.

## ✨ Features

- ⚡ **Live preview** that updates as you type
- 🔄 **Front and back** sides with a 3D flip animation
- 📸 **Photo upload** (image only, max 2 MB)
- ✅ **Form validation** with inline error messages
- 🎨 **Themes**, custom accent color and horizontal/vertical layout
- 🔳 **QR code** generated from the Student ID
- 🖨️ **Print** the card or **download** it as PNG/PDF
- 💾 **Auto-save** with localStorage
- 📱 **Responsive** on all devices

## 🧭 How to Use

1. Fill in your details and upload a photo
2. Click **Generate ID Card**
3. Pick a theme or color and click **Flip** to see the back
4. **Print** or **Download** your card

## 🚀 Run Locally

```bash
git clone https://github.com/<your-username>/idify.git
cd idify
```

Then open `index.html` in your browser, or use **Live Server** in VS Code.
